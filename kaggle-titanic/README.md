Titanic Survival Prediction Model:

This project primarily involves training the model that would predict the survival of a passenger based on estimates of prediction from the trained dataset.
Starting from using the data sets from Kaggle >> 
We need 2 sets of data :  Train dataset & Test Dataset
Then we need to clean both the datasets before we start with training the model since the data set includes multiple unwanted columns & NaN values. 
This cleaning also helps with standardizing the column values for data set which makes it easier to train the model so that prediction can be streamlined.
After the cleaning , we then begin with Modelling , where multiple ML models are imported such as Decision Tree Classifier , Random Forest Classifier , SVM , kNN & Naive Bayes.
Honestly , I am still learning with the use and impact of these ML models.
Lastly , after using these ML models and training such that we have prediction values/parameters from the training dataset , we begin with testing on the Testing dataset. 
Also make sure that this is also a cleaned data set with only necessary columns and all NaN are handled properly.
